It sounds like four tools: a finder, a reminder, a bodyguard and a janitor. It is one. Each file is read once, and everything else follows from that reading.

04 — What we said no to

The vault is a promise.
These are its terms.

  1. Noupload.

    Every file is read on your device. There is no cloud mode to switch on.

  2. Nodeleting.

    Files you let go move to a rest folder you can restore from. Only you empty it.

  3. Noguessing out loud.

    Draku suggests and you confirm. A date becomes a reminder only when you tap it.

  4. Noaccount, subscription or ads.

    It is free and open source.

  5. Nosettings screen.

    If a feature needs a setting, it is not finished.

06 — Why it has to be open

It reads your camera roll.
You should be able to read it back.

That roll holds IDs, prescriptions, tax forms and private photos. A product that reads it must run where it lives — and you must be able to check that it does.

Local needs open models.

PaddleOCR and EmbeddingGemma run on your own hardware, so reading a file never needs a server.

Open means checkable.

Anyone can read the code that reads their files and confirm that it never opens a network connection.

No storage ransom.

It costs nothing to run, because the models run on your hardware. A tool that frees your space never sells you more.

07 — Under the hood

Eyes, memory
and judgment.

Draku reads each file once — local OCR, a rule-based reader, and an open embedding model. Every outcome works from that reading.

FindPaddleOCREmbeddingGemma

Local OCR reads the pixels; a rule-based reader picks a name, category and key text. EmbeddingGemma embeds that reading, so a plain-language question finds the file.

Rememberlocal rules

The same reading extracts dates and their meaning from the surrounding words. A future date becomes a calendar file once you confirm it.

ProtectPaddleOCREXIF

The reading flags ID numbers, passwords and card numbers. Local OCR gives exact pixel positions; blurs are burned into the image and location metadata is stripped.

Let gotransparent scoring

One row per file: age, category, date passed, duplicate distance, blur, size. A small weighted score turns those signals into a reason you can read — and a button you choose to press.

08 — Questions

Sharp questions.
True answers.

Isn't this just Windows Recall?

Recall-style tools capture your screen over time so you can search it. Draku captures nothing: it reads only the files you choose, then acts on them.

How do I know nothing leaves the device?

The demo runs in airplane mode, and the code is open so anyone can check. Pull the network cable — Draku won't notice.

Why not a cloud gallery?

Cloud galleries work by uploading your files. Draku never does, and it goes beyond search: it renames, reminds, redacts and clears.

What if it misses a secret?

It shows every detection before you share, and you confirm. Blurs are burned into the image, so they cannot be peeled off.

How does Draku decide what is dead?

It adds up a few signals you can inspect: age, category, whether a date has passed, duplicate distance, blur and size. No training run, no hidden model — just weights in the source, and a button you choose to press.

Is the hosted demo a contradiction?

The hosted demo and any voiced video use sample files only, so people can try it with zero setup. The real product runs on your device. We say so plainly.
